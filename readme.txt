Projet réalisé lors de mon stage de 3eme au Mucem a Marseille en Décembre 2022



Étapes pour intaller MPilote en local :

1. Installer le logiciel MAMP puis le démarrer.

2. Ouvrir la page : localhost/MAMP.

3. Verifier le nom d'utilisateur et le mot de passe dans la catégorie "MySQL".

4. Aller dans le dossier MAMP/htdoc qui ce trouve à la racine de votre disque.

5. Supprimer tout les fichier de ce dossier si il y en a puis extraire le .zip ici.

6. Ouvrer le fichier "dbconnexion.php" avec votre éditeur de code favoris. (bloc-note suffit)

7. Dans ce fichier vérifier que "BDD_USER" et "BDD_PWD" sont bien égal à ce que vous avez trouver dans l'étape 2.

8. Render vour sur la page localhost/phpMyAdmin.

9. Si un mot de passe est demander ce sera ce que vous avez trouver à l'étape 2

10. Cliquer sur la catégorie "Import" puis selectionner le fichier .sql qui ce trouvera au même endroit les autres fichiers.

11. Une fois cela fais cliquer sur "Go".

12. Vous pouvez maintenant utiliser MPilote.
